# 가게 언어팩 만들기

**AI와 대화하면서, 우리 가게의 사실과 사장님의 말투를 담은 "언어팩"을 순서대로 만드는 템플릿입니다.**

AI에게 가게 글을 맡기면 매번 메뉴와 영업시간을 다시 설명하고, 말투를 고치고, 사실이 아닌 내용을 지워야 합니다. 언어팩은 그 기준을 한 번 정리해 두는 문서입니다. 글을 쓸 때마다 언어팩을 AI에게 함께 주면, 확인된 사실만으로 사장님 말투에 가까운 초안을 받을 수 있습니다.

> 이 템플릿은 글쓰기 기준 문서입니다. 설치하는 앱이 아니며, 검색 노출이나 매출을 보장하지 않습니다.

---

## 3단계로 시작하기

**① 파일 받기**
이 페이지 위쪽의 초록색 `Code` 버튼 → `Download ZIP`을 눌러 받고 압축을 풉니다.

**② AI에게 시작 요청문 붙여넣기**
[`START.md`](START.md)를 열어 상자 안의 요청문을 복사해 AI 대화창에 붙여넣습니다. `template` 폴더의 파일도 함께 첨부합니다.

**③ AI의 질문에 하나씩 답하기**
AI가 가게 자료부터 달라고 합니다. 플레이스 주소, 메뉴판 사진, 예전에 쓴 글을 주면 AI가 먼저 정리해서 보여주고, 사장님은 틀린 것만 고치면 됩니다. 모르는 칸은 "나중에"라고 하면 넘어갑니다.

---

## AI가 묻는 순서

| 단계 | 하는 일 | 사장님이 할 일 |
|---|---|---|
| 1. 자료 받기 | 플레이스 주소·메뉴판·소개 글·예전 글 | 있는 자료만 주기 |
| 2. 가게 사실 | 메뉴·가격·위치·영업시간·주차를 표로 정리 | 틀린 것만 고치기 |
| 3. 생각과 경험 | 쉬운 질문 하나씩 (선택) | 글에 써도 되는 것만 답하기 |
| 4. 고객 | 지금 손님과 늘리고 싶은 손님 | 두 가지를 나눠 답하기 |
| 5. 말투 | 내가 쓴 글, 좋아하는 참고 글, 두세 가지 말투 비교 | 마음에 드는 말투 고르기 |
| 6. 채널 | 스레드·블로그 등 채널별 역할과 태그·사진 규칙 | 쓸 채널만 고르기 |
| 7. 사진 권리 | 사진 묶음을 직접 촬영 / 허락 있음 / 모름으로 분류 | 묶음별로 확인 |
| 8. 게시 권한 | 기본은 초안까지만 | 게시를 맡길지 정하기 |
| 9. 첫 글 | 정리한 내용으로 첫 초안 작성 | 고치고, 계속 지킬 규칙 허락하기 |
| 10. 저장 | 채운 언어팩 파일과 미입력 목록 | 내 컴퓨터에 저장하기 |

긴 설문을 한꺼번에 채우지 않습니다. 첫 글을 함께 만들면서 부족한 것만 묻습니다.

---

## 좋아하는 글쓴이가 있다면

"이 사람처럼 쓰고 싶다"는 글이 있으면 5단계에서 알려 주세요. AI가 그 글의 문장 길이, 줄바꿈, 자주 쓰는 연결어와 끝맺음을 **숫자로** 정리해 언어팩에 적습니다.

문장이나 그 사람의 경험을 가져오지는 않습니다. 자세한 방법은 [`STYLE_REFERENCE.md`](STYLE_REFERENCE.md)에 있습니다. 파이썬을 쓸 수 있다면 `tools/style_profile.py`로 직접 셀 수도 있습니다.

---

## 언어팩으로 글 쓰기

언어팩을 만든 뒤에는 새 AI 대화에 내 `00_MASTER.md`와 `WRITING_POLICY.json`을 첨부하고, [`template/PROMPTS.md`](template/PROMPTS.md)의 요청문을 쓰면 됩니다.

| 요청 | 언제 |
|---|---|
| 작성 | 초안이 필요할 때. AI가 이번 글의 재료부터 정리하고 가장 강한 재료로 시작합니다 |
| 검수 | 초안의 사실·경험·사진 권리·금칙·반복을 점검할 때 |
| 승인 기록 | 마음에 든 본문을 기준으로 남길 때 (게시는 따로 정합니다) |

---

## 이 언어팩이 지키는 원칙

- **확인된 사실만 씁니다.** 모르는 가격·날짜·메뉴는 비워 두고 "확인 필요"로 남깁니다.
- **겪지 않은 일을 만들지 않습니다.** 사장님이 실제로 겪은 일만 1인칭으로 씁니다.
- **같은 구조를 반복하지 않습니다.** 그날의 재료(장면, 숫자, 손님 질문, 운영 기록)가 글의 시작과 구조를 정합니다.
- **사람처럼 보이려고 꾸미지 않습니다.** 일부러 오타를 넣거나 문장 길이를 흔들지 않습니다. 독자가 실제로 걸리는 것은 반복, 사실 오류, 구체성 없는 칭찬입니다.
- **초안과 게시는 다릅니다.** 기본은 초안까지이고, 실제 게시는 사장님이 따로 허락합니다.
- **비밀번호나 로그인 정보는 언어팩에 적지 않습니다.**

## 폴더 구성

```
START.md              AI에게 처음 붙여넣을 요청문 (여기서 시작)
STYLE_REFERENCE.md    좋아하는 글쓴이의 문체를 숫자로 분석하는 방법
template/
  00_MASTER.md        언어팩 본문 (가게 사실·경험·말투·채널·사진·승인)
  WRITING_POLICY.json 자동 검사 설정 (금칙어·반복 기준·채널 제한)
  PROMPTS.md          작성·검수·승인 기록 요청문
  README.md           템플릿 사용 안내
tools/
  style_profile.py    참고 글 문체 분석 도구 (선택, 파이썬 필요)
```

## 주의

- 내 가게 언어팩에는 주소, 전화번호, 사진 권리 같은 정보가 들어갑니다. **채운 언어팩을 공개 저장소에 올리지 마세요.** 이 저장소를 포크했다면 채운 파일은 비공개 저장소나 내 컴퓨터에만 두세요.
- 다른 사람의 글을 모은 파일도 공개하지 마세요. 언어팩에는 분석 결과만 적습니다.
- 같은 언어팩을 줘도 AI마다 결과가 다를 수 있고 틀린 내용을 쓸 수도 있습니다. 게시 전에 꼭 읽어 보세요.
