# 내 사업용 언어팩 시작하기

AI에게 이 폴더의 네 파일을 주고 `PROMPTS.md`의 만들기 요청을 전달하세요.
AI가 사업용 폴더를 복사하고 차례로 질문한 뒤 원본을 채웁니다. 파일을 손으로 만들거나 명령을 외울 필요는 없습니다.

`00_MASTER.md`에는 확인한 사실과 경험, 말투, 사진 권리, 승인 범위를 적습니다.
글마다 `이번 글의 재료` 표를 먼저 채우고, 그 재료로 글의 시작과 구조를 정합니다. 채널별로 맡는 역할도 여기에 적습니다.
`WRITING_POLICY.json`에는 검사 설정을 둡니다. `PROMPTS.md`에는 작성·검수·승인 기록 요청이 있습니다.
각 사업의 복사본이 원본입니다. 다른 매장 원본을 덮어쓰는 전용 동기화 명령은 사용하지 않습니다.

AI는 1단계 자료를 받은 뒤 고유한 사업 ID 후보를 제안하고, 확인을 받아 `pack_id`를 `owner-voice-template`에서 바꿉니다.
ID는 영문 소문자나 숫자로 시작하며 영문 소문자·숫자·밑줄·하이픈으로 1~64자입니다.
본문 사실을 정책에 중복 저장하지 않습니다. 수정 전 복사본을 보관하고 이번 글 요청과 상시 규칙 승인을 구분합니다.

기본 금칙·허용 반복 문구·말투는 비어 있습니다. 검사에 걸리지 않았다는 결과가 본인 기준 확인 완료를 뜻하지 않습니다.
사진 허용 `true`는 채널별 금지가 아직 없다는 뜻입니다. 사진 사용 권리 승인이나 자동 첨부 지시가 아닙니다.
장소 카드 필수 여부도 사업별로 확인합니다.

`WRITING_POLICY.json`의 주요 항목은 이런 뜻입니다.

| 항목 | 뜻 |
|---|---|
| `preferences.thread_chars` | 스레드 **권장 분량**입니다. 벗어나면 경고만 합니다 |
| `channels.thread.max_chars` | 검사 도구가 막는 **상한**입니다. 최신 앱 제한으로 확인된 값은 아닙니다 |
| `rules.blog_numbered_list_forbidden` | `true`면 블로그 본문에서 `1. `처럼 **숫자+마침표+띄어쓰기로 시작하는 줄**을 막습니다. `1)`, `①`은 막지 않습니다 |
| `channels.blog.native_place_card_required` | `true`면 네이버 글마다 장소(지도) 카드를 넣습니다 |
| `channels.blog.serp_card` | 네이버 검색 카드 발행 전 점검 기준입니다. 첫 문단의 제목 검색어 답, 서로 다른 사진 최소 5장·목표 8~10장·최대 10장, 대표 사진 우선 순서를 기록합니다. 사진 10장은 관찰값이며 공식 보장이 아닙니다 |
| `channels.thread.photos_allowed` | 스레드에 사진을 쓸 수 있는지. 사진 권리 승인과는 다릅니다 |

스레드 `max_chars: 500`은 기존 도구의 설정값이며 최신 채널 제한으로 검증되지 않았습니다.
`limit_status: legacy_unverified`, `checked_at: null` 상태를 그대로 공개하고 실제 채널 제한은 공식 자료 또는 편집기에서 확인합니다.
문장 중복 10%·반복 3개, 어구 기본 12자, 구성 비교 최근 5편·같은 조합 2회 경고는 초기 검사 설정입니다. 노출이나 성과의 공식이 아닙니다.

처음에는 비교 자료가 없습니다. AI는 문장·어구 비교 불가와 구성 이력 부족을 각각 알려야 합니다.
검사 도구가 없는 모델에는 수동으로 확인한 항목과 미검증 항목을 나눠 달라고 하세요. 실행하지 않은 검사를 통과했다고 해서는 안 됩니다.

첫 글의 가게 식별 정보, 이번 글에 쓸 사실, 말투, 채널·주제가 확인되면
`첫 글 작성 준비 완료`로 구분할 수 있습니다. 선택 항목은 `미입력`으로 남겨도 됩니다.
선택 항목까지 모두 채웠다는 뜻의 `전체 설정 완료`와 혼동하지 않습니다.

블로그 편집 블록을 상시 필수로 정하고 자동 검사하기로 승인한 경우에만
`CHANNELS.md`에 문서화된 `channels.blog.editor_blocks`를 정책에 추가합니다.
이 항목이 없으면 `editor_blocks_check.py`를 실행하지 않습니다. `serp_card`는 발행 전 수동 점검 기준이며, 이 저장소의 기존 검사기가 첫 문단 답이나 사진 장면 다양성을 자동 판정한다고 보고하지 않습니다. 문서화되지 않은 다른 JSON 필드는 임의로 만들지 않습니다.

공개 발행은 별도 승인입니다. 초안 승인 시에는 승인한 본문과 실제 근거만 기록하고 공개 URL과 게시 시각을 채우지 않습니다.
확인되지 않은 필수 사실이나 사진 권리가 남았다면 공개 가능한 완성본으로 보고하지 않습니다.
다른 모델에서도 문서를 읽을 수 있지만 같은 결과나 도구 실행을 보장하지는 않습니다.
